# Монтажный план для ПК

Рабочая папка содержит job.json (технические параметры и источники) и edit-plan.json (монтаж). Все времена at/frames — целые кадры итогового FPS; source_start_s — секунды оригинала. Путь file абсолютный либо относительно папки ролика. Для 30 секунд при 30 fps сумма cuts — ровно 900 кадров. FPS не ускоряет речь.

Минимальный пример структуры (пути и таймкоды выбираются после анализа, это не предложение брать первые 30 секунд):

    {
      "version": 1,
      "cuts": [
        {"file": "D:/Видео/исходник.mp4", "source_start_s": 125.4, "frames": 450, "fit": "cover", "focus": [0.6, 0.5], "zoom": [1, 1.08], "zoom_anchor": [0.5, 0.4], "gain_db": 0, "why": "хук и объяснение"},
        {"file": "D:/Видео/исходник.mp4", "source_start_s": 240.0, "frames": 450, "fit": "contain", "why": "результат и завершение"}
      ],
      "overlays": [
        {"file": "graphics/card.png", "at": 60, "frames": 90, "rect": [80, 300, 920, 500], "fit": "contain", "fade_s": 0.15}
      ],
      "audio": [
        {"file": "audio/music.wav", "source_start_s": 3, "at": 0, "frames": 900, "gain_db": -22}
      ],
      "captions": [
        {"at": 15, "frames": 45, "text": "Точный текст речи."}
      ],
      "caption_style": {"font": "Onest", "size_px": 64, "color": "#FFFFFF", "outline_color": "#161616", "outline_px": 3, "x": 500, "y": 1500}
    }

## Что поддерживается

- cuts: последовательные куски, source_start_s, frames, contain/cover, focus, background (black/white/0xRRGGBB), gain_db, zoom [начало,конец] от 1 до 1.3, zoom_anchor [x,y] 0..1. why — обоснование выбора. Кадрирование запекается в производный клип, зум остаётся ключами в CapCut.
- contain помещает весь кадр в вертикальный холст с полями; cover заполняет холст с обрезкой. focus задаёт долю доступного смещения кропа по каждой оси: 0 — край начала, 0.5 — центр, 1 — край конца. Это не координаты лица в пикселях.
- overlays: изображение/видео, исходный старт, at, frames, rect [x,y,w,h], fit/focus/background, fade_s, why. Координаты/размеры чётные, внутри холста. По умолчанию overlay без звука; нужный звук указывается отдельно в audio. Несколько слоёв могут перекрываться, поздний элемент находится выше.
- audio: отдельные отрезки музыки, озвучки и SFX, at/frames/source_start_s/gain_db/why. Громкость запекается в WAV. Музыкальный ducking под речь заранее готовится отдельной дорожкой; нет скрытой автоматической обработки.
- captions: непустой текст, at и frames, порядок по времени без пересечений. Необязательный style: {x, y, size_px} переопределяет положение и размер конкретного сегмента в локальном рендере и native-тексте; координаты внутри холста, размер 12–160 px. Сохранены знаки препинания. Перенос строки — обычный JSON-символ новой строки. Управляющие вставки ASS не принимаются.
- caption_style: font (семейство), font_file (путь TTF), size_px, color/outline_color (#RRGGBB), outline_px, x/y. Шрифт должен поддерживать русский. Размещение и переносы CapCut и ASS необходимо сравнить визуально: это разные текстовые движки.

Неизвестные поля отклоняются. Произвольные transitions, speed, blur, masks, покадровая подсветка слов не притворяются работающими: заранее подготовь такой фрагмент/оверлей или реализуй и проверь конкретное расширение.

## Команды

<S> — .agents/skills/reel-director, <J> — папка ролика. Пути с пробелами заключай в кавычки.

    node "<S>/scripts/desktop.mjs" init-plan --job "<J>"
    node "<S>/scripts/desktop.mjs" validate --job "<J>"
    node "<S>/scripts/desktop.mjs" prepare --job "<J>"
    node "<S>/scripts/desktop.mjs" render --job "<J>"

prepare создаёт новую неизменяемую папку prepared/ID и prepared.json с контрольными суммами. Сами исходники не меняются. Каждый cut — качественный H.264/AAC с итоговым размером/FPS; overlay — полноразмерный прозрачный ProRes 4444; audio — PCM WAV. Поля и прозрачность нужно смотреть. Для уже низкого исходного разрешения сохранение 1080×1920 не означает восстановления деталей.

После изменения плана prepare выполняется снова; старые файлы, на которые ссылается проект, остаются. Большие ProRes могут занимать много места, проверь свободный диск перед сложной графикой. Параллельная работа с одной папкой блокируется lock-файлом; не удаляй его при живом процессе.

render создаёт export/ID/reel.mp4, captions.srt, captions.ass, filter.txt и render-report.json. Субтитры в MP4 запечены, в CapCut остаются текстом. Это локальный рендер, а не вызов экспорта CapCut. В миксе локального рендера есть финальный лимитер; итог из приложения проверь отдельно.
