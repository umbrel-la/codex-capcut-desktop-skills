# Черновой монтаж для CapCut на ПК

Прочитай [выбор задачи](../reel-director/references/task-routing.md). Для нового рилса анализируй весь исходник и выбирай законченную историю. Для удаления пауз/дублей сохраняй содержание и порядок оставшегося материала без автоматического сокращения до 30 секунд. Для одной графики/субтитров нужен capcut-finish, а не новый отбор фраз. Действующие команды — ../reel-director/scripts.

- Прочитай технические данные через reel.mjs inspect FILE. Анализируй весь файл, включая конец. Для большого исходника локальное чтение достаточно; загрузка в CapCut Web не требуется.
- Создай обзор: desktop.mjs sheet --file VIDEO --out NEW.jpg --count 30. Это навигационный контакт-лист, не доказательство полного просмотра. Уточняй важные интервалы отдельными кадрами и прослушиванием.
- Используй доступный локальный ASR. transcribe.py требует установленный faster-whisper и явный локальный каталог CTranslate2-модели, ничего не скачивает. Пример: PYTHON transcribe.py --source VIDEO --out analysis/transcript.json --model LOCAL_MODEL. Существующая .venv-asr и .asr-models родительской папки могут подойти: сначала проверь наличие. Без ASR не сочиняй расшифровку; назови отсутствующую зависимость, продолжи визуальный анализ.
- В coverage.json укажи общую длительность, способ анализа, обработанные интервалы и пробелы. Наличие ASR не означает просмотра всех кадров. Прочитай текст целиком; проверь пропуски и спорные слова по звуку.
- При создании рилса определи одну мысль: хук, развитие, завершение. При чистке речи сохрани исходную историю. Выбирай удачное исполнение, а не обязательно последний дубль. Сохраняй смысл, речь и дыхание; не ускоряй голос ради шаблонной длительности и не обрезай слова. Более короткую мысль выбирай только при задаче отбора под заданную длительность.
- Сравни звук и губы на опорных согласных. Исходный рассинхрон зафиксируй; не компенсируй случайной универсальной задержкой. При VFR используй подготовленные CFR-клипы и проверяй начало/конец.
- Сохрани story.md: исходные таймкоды, текст, причины выбора и склеек. edit-plan.json хранит cuts с source_start_s и целым frames. Отбор может начинаться с любой точки исходника.
- Громкость подбирай по измерению и прослушиванию. Цель порядка −16 LUFS / −1 dBTP — ориентир речи, а не автоматические +9 dB. Нормализацию делай в отдельный производный файл в audio/ с сохранёнными параметрами. Не заменяй оригинал и не включай цветокоррекцию без просьбы.
- Для горизонтального материала выбирай contain либо осмысленный cover с focus. При записи экрана сохраняй важные кнопки/текст: отдельный увеличенный фрагмент, компоновка или вставка, а не слепой кроп.

Далее [схема плана](../reel-director/references/desktop-plan.md) и [чистовой навык](../capcut-finish/SKILL.md). При запросе только черновика не добавляй генерации и декоративные слои.
